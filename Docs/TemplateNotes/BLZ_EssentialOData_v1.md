# BLZ_EssentialOData_v1

The `OData` essentials group of the Blazor stack (written once and kept; `--replace` refreshes it; `OData=true` ticks it): `Services/ODataSupport.cs` and `wwwroot/css/odata.css`. It is the Blazor twin of `TSX_EssentialOData`; `index.html` (the Project group) links the style sheet when `OData=true`. It needs `Services/ApiSupport.cs` (the Support group).

- `ODataApiException`: an `ApiException` that also holds the detail of the API's problem answer (the words of a 409). `ExplainOData(action)` is the sentence a page shows: the API's own words for a conflict, "in use" for a delete the database refused, else the usual `Explain`.
- `ODataQuery`: `ODataString` / `Literal` (a text becomes one quoted literal with every quote doubled, so whatever a person types stays one value; a number, a date, a guid and a yes/no are written by type), `Contains` / `ContainsAny` (`contains(tolower(name),'text')`), `And`, `OrderBy`, `Query` (every value URL-encoded) and `RelativeLink` (the server's next link without its host).
- `ODataFilters.ConditionsOf`: the filter row. One `ODataFilterField` per grid column (`ODataFilterFields` in Core, the rule every web stack uses) and a `ColumnFilter` for what was typed: a text the property contains, a number or date range (the last day of a date range is included), yes or no, one value of a parent or of the listed choices, and "empty". A number, date or guid that is not one throws `FormatException` and is never sent.
- `ODataClient<T, TKey>`: the calls of one table over `GET /odata/<set>`: `GetAllAsync` (follows the next links), `GetWhereAsync(property, value)` (a child grid reads its parent's rows with it), `GetAsync`, `CreateAsync`, `UpdateAsync`, `DeleteAsync` on the key route, `CloneAsync` through the table's REST route (there is no OData verb for it) and `QueryPageAsync` (`$count`, `$top`, `$skip`, `$filter` for the search boxes and the filter row, `$orderby` for the sorts and then the default order).
- `SavedSorts`: keeps the sorts of a grid in localStorage (`LoadAsync`, `SaveAsync`, `Parse`); blocked storage or a stored value that is not a sort list is the same as nothing saved. `ODataPageQuery.Select` adds a `$select` of the key and the listed properties to `QueryPageAsync`.
- `odata.css`: the number that says the place of a column in a several-column sort, and the filter row.
