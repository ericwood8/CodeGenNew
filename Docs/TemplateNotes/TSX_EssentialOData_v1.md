# TSX_EssentialOData_v1

The `OData` essentials group of the React stack (written once and kept; `--replace` refreshes it). `OData=true` ticks it for a React project, as it does for Angular.

- `src/api/odataQuery.ts`: `odataString` and `odataLiteral` (a text becomes one quoted literal, a quote doubled, so what a person types can never end the literal; a bad number, date or guid is refused, never sent), `containsText` and `containsAny`, `and`, `orderBy`, `conditionFilter` (a filter row condition as a piece of `$filter`: contains, a range, an exact value or empty), `queryString` (every value goes through `encodeURIComponent`, so a plus sign or an ampersand cannot change the query) and `relativeLink` (the server's `@odata.nextLink` without its host, so the call goes through the same origin and proxy).
- `src/api/odataClient.ts`: `createODataApi<T, K>(set, table, restPath)`, the calls of one table over `GET /odata/<set>` with the method names of the REST api modules: `getAll` (follows the next links), `getLookup` (`$select` of the key, the display column and the active flag), `getById`, `create`, `update`, `delete`, `getPage` and `queryPage` (`$count`, `$top`, `$skip`, `$filter`, `$orderby` with several sorts and a parent's display column, `$select` of the columns the grid shows and the key). `clone` and `getGuards` go through the table's REST route. Also `readOData` (a path read to the end of its pages), `problemText` (the `detail` of a problem answer) and the `PagedResult` shape.
- `src/components/odataScreen.tsx` and `odataGrid.css`: the saved sorts (the same `gridSort:<key>` list the single sort uses), `nextSorts` (a click sorts, a Shift-click adds the column, again flips it, once more takes it out), `ODataSortHeader` (the mark and the number that says the column's place), `conditionsOf` and `FilterCell` (the control of a filter row column by its kind).
- Tests: `api/__tests__/odataQuery.test.ts`, `odataClient.test.ts` and `components/__tests__/odataScreen.test.tsx` (Vitest; `fetch` is mocked).

Needs `api/client.ts` and `components/gridSort.tsx` (the Support and GridSort groups). The dev proxy (`vite.config.ts`) and the container's nginx forward `/odata` when `OData=true`; a project made before needs `--replace` of the Build and Docker essentials for those two.
